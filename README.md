# Steal a Brainrot Hub

Script hub for Roblox game "Steal a Brainrot"

## How to Use

1. Join the game: https://www.roblox.com/games/109983668079237/Steal-a-Brainrot
2. Open your executor
3. Paste this:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dimitar26052009-cloud/StealABrainrotHub/main/loader.lua"))()
```

4. Execute and press RIGHT SHIFT to toggle UI
